# UBoard Quad Motors Module

Быстрый старт по работе с 4-канальным драйвером DC-моторов*

UBoard Quad Motors Module — четырёхканальный драйвер коллекторных DC-моторов на базе SS6285M. Модуль позволяет независимо управлять четырьмя двигателями: задавать направление вращения, скорость и режим торможения.

Управление выполняется обычными GPIO микроконтроллера или одноплатного компьютера. Для каждого двигателя используются два цифровых входа управления.

Модуль рассчитан на питание двигателей 3–33 В и ток нагрузки до 6 А на канал. Управляющая часть работает с логическими уровнями 3,3–5 В и гальванически изолирована от силовой части.

1. Разъёмы платы

На плате расположены четыре силовых выхода:

Motor 1 / Motor 2 / Motor 3 / Motor 4

Каждый выход предназначен для подключения одного DC-мотора.

Питание двигателей подключается через центральный силовой разъём:

Контакт	Назначение
VIN	Питание двигателей, 3–33 В
GND	Минус источника питания

Например, при использовании двигателей на 12 В к VIN подключается +12 V, а к GND — минус источника питания.

Напряжение источника необходимо выбирать исходя из допустимого напряжения подключённых двигателей.

2. Управляющие входы

Каждый мотор управляется двумя сигналами:

INxA и INxB

где x — номер двигателя.

Например, для первого двигателя:

IN1A
IN1B

для второго:

IN2A
IN2B

и так далее до Motor 4.

На управляющих разъёмах также доступны:

GND
VCC

VCC — питание логической части 3,3–5 В.

3. Управление направлением

Направление вращения задаётся состояниями входов A и B.

INxA	INxB	Состояние двигателя
0	0	Свободный ход
1	0	Вращение в одну сторону
0	1	Вращение в обратную сторону
1	1	Торможение

Например:

IN1A = HIGH
IN1B = LOW

Motor 1 вращается в одном направлении.

Меняем сигналы местами:

IN1A = LOW
IN1B = HIGH

Motor 1 вращается в противоположном направлении.

Какое из направлений физически будет «вперёд», зависит от полярности подключения двигателя.

4. Управление скоростью через PWM

Для регулирования скорости на один из входов подаётся PWM, а второй удерживается в фиксированном состоянии.

Вращение вперёд
INxA = PWM
INxB = LOW

Скважность PWM определяет среднюю мощность, подаваемую на двигатель.

Например:

Duty = 0%     → двигатель остановлен
Duty = 25%    → низкая скорость
Duty = 50%    → средняя скорость
Duty = 100%   → максимальная скорость

Фактическая скорость зависит от двигателя, нагрузки и напряжения питания, поэтому зависимость скорость ↔ duty cycle не обязательно линейная.

Вращение назад

Для обратного направления:

INxA = LOW
INxB = PWM

Таким образом, одним и тем же PWM можно управлять скоростью в обоих направлениях.

5. Пример управления одним мотором

Допустим:

IN1A → GPIO17
IN1B → GPIO18

Тогда логика программы может выглядеть следующим образом:

// Вперёд
IN1A = PWM;
IN1B = LOW;

// Назад
IN1A = LOW;
IN1B = PWM;

// Свободный ход
IN1A = LOW;
IN1B = LOW;

// Торможение
IN1A = HIGH;
IN1B = HIGH;

Например, для движения вперёд с мощностью 50%:

IN1A = PWM 50%
IN1B = LOW
6. Управление четырьмя двигателями

Все четыре канала независимы:

Motor 1 → IN1A / IN1B
Motor 2 → IN2A / IN2B
Motor 3 → IN3A / IN3B
Motor 4 → IN4A / IN4B

Поэтому можно одновременно задавать разные скорости и направления.

Например, для четырёхколёсной платформы:

Motor 1 → 70% вперёд
Motor 2 → 70% вперёд
Motor 3 → 50% вперёд
Motor 4 → 50% вперёд

Или реализовать разворот на месте:

Motor 1 → вперёд
Motor 2 → вперёд

Motor 3 → назад
Motor 4 → назад
7. Типовая схема подключения

Минимальная конфигурация выглядит так:

            UBoard Quad Motors Module
          ┌──────────────────────────┐
          │                          │
12V  ────►│ VIN                      │
GND  ────►│ GND                      │
          │                          │
MCU ─────►│ VCC                      │
GPIO ────►│ IN1A          MOTOR 1 ───┼── DC Motor
GPIO ────►│ IN1B                     │
          │                          │
GPIO ────►│ IN2A          MOTOR 2 ───┼── DC Motor
GPIO ────►│ IN2B                     │
          │                          │
GPIO ────►│ IN3A          MOTOR 3 ───┼── DC Motor
GPIO ────►│ IN3B                     │
          │                          │
GPIO ────►│ IN4A          MOTOR 4 ───┼── DC Motor
GPIO ────►│ IN4B                     │
          └──────────────────────────┘
